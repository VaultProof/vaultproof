Setup Guide

Protect every API key in your project in under 2 minutes.

1. Protect 2. Add more 3. Rotate 4. Deploy
1

Protect your keys

Run one command in your project directory. It scans your .env, finds every API key, and protects them all.

$ npx @vaultproof/init
VaultProof — scanning .env...
Found 3 API keys:
  ✓ OPENAI_API_KEY         (OpenAI)
  ✓ STRIPE_SECRET_KEY     (Stripe)
  ✓ ANTHROPIC_API_KEY     (Anthropic)
Done. Your .env uses one project ID for everything:
  vp-proj-abc123
✓

Each key is Shamir-split in your terminal — the plaintext never leaves your machine. Your .env is rewritten with one vp-proj- project ID. Your code doesn't change.

2

Add more keys later

Two ways to add keys after the initial setup.

From the terminal

Add the new key to your .env and run init again. It detects the new key and adds it to your existing project.

npx @vaultproof/init

From the dashboard

Go to vaultproof.dev/app/keys, click + on your project, paste the key. Auto-detects the provider.

Paste key → auto-detect → Split & Protect
3

Rotate a key

When you rotate a key at the provider (OpenAI, Stripe, etc.), update VaultProof in 30 seconds.

  1. 1 Rotate the key in the provider's dashboard (OpenAI, Stripe, etc.)
  2. 2 Go to vaultproof.dev/app/keys, click Rotate on the key, paste the new value
  3. 3 Done. Your project ID stays the same. Zero code changes, zero redeployments.

Or from the terminal: put the new key in .env and run npx @vaultproof/init again.

4

Deploy

Set your project ID and provider base URLs in your hosting environment. That's it — no secrets to manage.

# Set these in Vercel / Railway / Netlify / Fly / etc.
VAULTPROOF_PROJECT_ID=vp-proj-abc123
OPENAI_BASE_URL=https://init.vaultproof.dev/p/openai/v1
OPENAI_API_KEY=vp-proj-abc123
STRIPE_BASE_URL=https://init.vaultproof.dev/p/stripe
STRIPE_SECRET_KEY=vp-proj-abc123
✓

None of these values are secrets. The project ID is a public identifier — safe to commit, safe to share. Your real keys exist only as encrypted Shamir shares on the VaultProof proxy.

Works with every provider. OpenAI, Anthropic, Stripe, Groq, Mistral, Together, Fireworks, DeepSeek, xAI, OpenRouter, Resend, SendGrid, Linear, Notion, GitHub — and any custom API via the dashboard.

npx @vaultproof/init
