API Documentation

Everything you need to integrate VaultProof into your app.

Quick Start

Three lines. That's it.

// 1. Install
npm install @vaultproof/sdk

// 2. Initialize with your developer API key
import VaultProof from '@vaultproof/sdk'
const vault = new VaultProof('vp_live_abc123...')

// 3. Store a key and make proxied calls
const key = await vault.store('sk-openai-key', 'openai', 'Production')

const res = await vault.proxy(key, '/v1/chat/completions', {
  model: 'gpt-4',
  messages: [{ role: 'user', content: 'Hello!' }]
})

Base URL

https://api.vaultproof.dev

All requests go through Cloudflare's edge network (330+ cities). HMAC-signed and rate-limited.

Authentication

POST /api/v1/auth/register

Create a new account.

Request:  { "email": "you@example.com", "password": "min8chars" }
Response: { "token": "eyJ...", "user": { "id": "uuid", "email": "..." } }
POST /api/v1/auth/login

Login and get a JWT token (valid 7 days).

Request:  { "email": "you@example.com", "password": "yourpass" }
Response: { "token": "eyJ...", "user": { "id": "uuid", "email": "..." } }

Include the token in all subsequent requests: Authorization: Bearer <token>

Developer API Keys

Developer API keys let you authenticate SDK calls without managing JWTs. They use a vp_live_ prefix and are scoped to your account.

Getting Your Key

  1. Go to Settings → API Keys → Create Key
  2. You'll receive a vp_live_ prefixed key
  3. Add it to your .env file:
VAULTPROOF_API_KEY=vp_live_...

Using With the SDK

import VaultProof from '@vaultproof/sdk'

const vault = new VaultProof(process.env.VAULTPROOF_API_KEY)
// That's it — all SDK methods are now authenticated

Key Management

POST /api/v1/keys/store Auth required

Store a Shamir-split API key. Send only Share 1 (encrypted server-side). Keep Share 2 on device.

Request: {
  "provider": "openai",        // openai | anthropic | google | together
  "label": "Production GPT-4", // optional friendly name
  "share1": "base64...",       // Shamir Share 1 (base64 serialized)
  "vaultCommitment": "hex...", // Hash commitment for ZK verification
  "appId": "my-app",           // optional app identifier
  "appName": "My App"          // optional app name
}
Response: { "keySlotId": "uuid", "grantId": "uuid", "status": "stored" }
GET /api/v1/keys/list Auth required

List all your active keys with connected apps.

Response: {
  "keySlots": [{
    "id": "uuid",
    "provider": "openai",
    "label": "Production GPT-4",
    "status": "ACTIVE",
    "createdAt": "2026-03-24T...",
    "appGrants": [{ "id": "uuid", "appId": "my-app", "appName": "My App" }]
  }]
}
POST /api/v1/keys/revoke/:keySlotId Auth required

Revoke a key. Destroys Share 1 (zeroed in DB). Irreversible.

POST /api/v1/keys/:keySlotId/rotate Auth required

Rotate a key with a new Shamir share. Old share is replaced.

Proxied API Calls

POST /api/v1/proxy/call

Make an API call through VaultProof. Key is reconstructed ephemerally (~100ms) then zeroed. Supports SSE streaming for LLM APIs.

Request: {
  "keySlotId": "uuid",            // from /keys/store response
  "share2": "base64...",          // your Share 2 (stored on device)
  "zkProof": "hex...",            // ZK proof of authorization
  "nullifier": "hex...",          // unique per request (replay prevention)
  "appId": "my-app",              // must be an authorized app
  "targetPath": "/v1/chat/completions",  // API endpoint
  "method": "POST",               // HTTP method
  "stream": false,                // true for SSE streaming
  "body": {                       // forwarded to the API provider
    "model": "gpt-4",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }
}
Response: // The API provider's response, forwarded directly

Security: Every call requires a unique nullifier (prevents replay). The ZK proof cryptographically proves you own the key slot and the requesting app is authorized. The SDK handles all of this automatically.

SDK Endpoints

POST /api/v1/sdk/store API Key required

Store an API key via the SDK. Shamir-split and encrypted server-side.

Request: {
  "apiKey": "sk-...",          // the API key to store
  "provider": "openai",        // openai | anthropic | google | together
  "label": "Production"        // optional friendly name
}
Response: { "keyId": "uuid", "status": "stored" }

Make a proxied API call through VaultProof.

Request: {
  "keyId": "uuid",             // from /sdk/store response
  "share2": "base64...",       // Share 2 (returned by SDK)
  "path": "/v1/chat/completions",  // API endpoint
  "method": "POST",            // HTTP method
  "body": { ... }              // forwarded to the API provider
}
Response: // The API provider's response, forwarded directly
GET /api/v1/sdk/keys API Key required

List all stored keys for this developer API key.

POST /api/v1/sdk/revoke API Key required

Revoke a stored key. Irreversible.

Request: { "keyId": "uuid" }
Response: { "status": "revoked" }

Security Architecture

Shamir Secret Sharing

Your API key is split into 2 shares using GF(256) polynomial interpolation. Neither share alone reveals anything. Half a key is cryptographic garbage.

AES-256-GCM Encryption

Share 1 is encrypted at rest with a unique salt and IV per encryption. Tampered data is detected and rejected via auth tag.

Zero-Knowledge Proofs

Noir ZK circuit proves key ownership and app authorization without revealing the key. Verified with Barretenberg on every proxy call.

Ephemeral Reconstruction

The full API key exists in memory for ~100ms during the proxied call, then is zeroed. It never hits disk, logs, or persistent storage.

HMAC-Signed Edge Proxy

All requests are HMAC-SHA256 signed at Cloudflare's edge. Backend rejects unsigned requests. Direct access is blocked.

Nullifier Replay Prevention

Every proxy call requires a unique nullifier stored in DB. Replayed requests are detected and rejected instantly.
