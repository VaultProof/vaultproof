Getting Started

1

Sign Up

Create your account with GitHub, Google, or email

Go to Login
2

Store Your First Key

Go to API Keys, click "Add Key", paste your key. It's split instantly.

Go to API Keys
3

Use the Proxy

Replace your API base URL with VaultProof's proxy URL. One line change.

// Before:
fetch('https://api.openai.com/v1/...')
// After:
fetch('https://api.vaultproof.dev/v1/...')
4

Monitor Usage

Check Access Logs to see every API call, who made it, and when.

Go to Access Logs

Using the CLI

1

Install

$ npm install -g @vaultproof/cli
2

Login & Setup

$ vaultproof login
$ vaultproof dev-key create -l "my-app"
$ export VAULTPROOF_API_KEY=vp_live_...
3

Store a Key

$ vaultproof store -p openai
# Paste your key — it's split locally, server never sees it
4

Use in Your App

# Inject keys as env vars
$ vaultproof exec -p openai -- node app.js
# Or export manually
$ eval $(vaultproof env -p openai)
5

Monitor

$ vaultproof keys # List stored keys
$ vaultproof logs # View access logs
