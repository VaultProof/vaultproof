Welcome to VaultProof

One command protects every API key in your project. Your keys are split with Shamir Secret Sharing and only assembled briefly during each API call.

1

Run one command

In your project directory, run npx @vaultproof/init. It scans your .env and finds every API key automatically.

2

Your keys are protected

Each key is Shamir-split locally and uploaded as encrypted shares. Your .env is rewritten with one vp-proj- project ID for everything.

3

Your code doesn't change

Your SDKs read the proxy URLs from the environment automatically. Requests flow through init.vaultproof.dev — your real keys stay hidden.
