Key Splitting

Your API key is split into shares using Shamir Secret Sharing the instant you paste it. The original is destroyed in-browser. Half a key is cryptographic garbage.

Budget Caps

Set daily and monthly call limits on each stored key. When the cap is hit, VaultProof blocks the call -- so a bug or stolen key can't run up your bill.

Auto-Fallback

Store keys for multiple providers. If OpenAI returns a 500, VaultProof automatically retries with Groq or Together. Your agent never stops working.

Kill Switch

Something wrong? One click to freeze ALL proxy calls instantly. Requires typing "STOP" + your password to prevent accidents. Resume when you're ready.

.env Import
